# 📚 BookNook - Books & Stationery

BookNook is a modern, responsive frontend-only online bookstore built using React.js, JavaScript and CSS.

## 🚀 Features

- Responsive homepage
- Books and stationery catalog
- Product search
- Category filtering
- Subcategory filtering
- Price filtering
- Rating filtering
- Product sorting
- Product details
- Author pages
- Product reviews
- Shopping cart
- Quantity management
- LocalStorage cart persistence
- Coupon system
- Checkout page
- Client-side form validation
- Mock payment options
- Mock order confirmation
- Dark mode
- Responsive mobile navigation
- Toast notifications
- Responsive design
- SEO-friendly metadata

## 🛠 Technology

- React.js
- JavaScript ES6+
- CSS3
- React Router
- Browser LocalStorage
- Vite

## 📁 Run Locally

Install dependencies:

```bash
npm install
```
